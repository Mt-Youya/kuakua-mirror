# 夸夸镜 · 黑客松版

一句话：**照镜子 → 它看图、听你说话 → 用第一人称真诚地夸你一句，并念给你听。**
这一版把之前的痛点全部解决：提示词最新、输出和测试台一模一样、出声飞快、一整天不重样。

---

## 我要怎么操作才能得到夸夸？

**第 1 步：双击 `启动夸夸镜黑客松版.bat`**
（第一次会自动装依赖，等它出现"浏览器打开: http://127.0.0.1:5680"，并自动弹出浏览器。）

**第 2 步：在浏览器里点「打开镜子」，允许使用摄像头。**

**第 3 步：二选一**
- **演示模式（路演推荐，超级快）**：点亮「⚡ 演示模式」。镜子会在后台默默准备好夸夸 + 配音，
  你一点「再夸一次」、或它自动夸，都是**秒出声**（实测约 9 毫秒）。
- **实时模式**：不开演示模式，每次「再夸一次」现场看图现做，约 8–12 秒出一句。

> 提示：演示模式下，右下角小标签会显示「池 X/3」，表示后台备好了几句。等它 ≥1 再点，就是秒出声。

## 它是怎么做到"又快、又不重复、又和测试台一样好"的？

### 1. 输出效果和提示词测试台完全一致（核心需求）
- 用的是**同一份提示词文件**（测试台保存/同步的那份 `prompts_live.json`），改提示词这边自动生效。
- 模型、温度、字数上限、质量闸门（22 字内 / 第一人称 / 不说"你" / 不给建议 / 不套话）逐项一致。
- 在测试台基础上只**收紧**不放宽：额外屏蔽"开心/俏皮/眼镜"，叠加防重复闸门。

### 2. 输出速度（超级重要）
旧版是"单格缓存、取后即焚"，所以经常出现"1 秒点一下、十几秒才出声"。
这一版改成**服务端常驻 3 条预计算池**：
- 后台提前把"看图 → 夸夸 → 过闸门 → 配音"全做完，存进池子；
- 你要夸的时候，池里有现成的就**直接毫秒级返回**（连音频都备好了）；
- 取走一条，后台立刻补一条，池子始终保持充盈。
- 实测：即时播放约 **9 毫秒**；实时现做约 8–12 秒（这是模型思考时间，属正常）。

### 3. 不重复任何一条夸夸（非常重要）
三层保险：
1. **生成时**：把最近说过的话喂给模型，让它主动避开；
2. **生成后**：和**全部历史**做相似度比对，太像就打回重做（最多 3 次）；
3. **兜底**：连重做都撞车时，从 12 句兜底句里挑一句**没说过**的。
- 所有说过的夸夸都写进 `praise_history.json`，**重启也不忘**，一整天路演不重样。

## 架构一览（5 个模块，各司其职）

| 文件 | 职责 |
|---|---|
| `config.py` | 配置中心：API、模型、管线参数、**提示词热加载** |
| `pipeline.py` | 核心管线：看图∥听对话→夸夸→质量闸门→防重复闸门 |
| `pool.py` | **提速核心**：常驻 3 条已配音夸夸，随取随补 |
| `store.py` | 全局夸夸历史落盘（防重复的事实来源） |
| `voice.py` | 语音：转写（听）+ 合成（说） |
| `app.py` | Flask 路由，把上面串起来，端口 **5680** |

数据流：`拍照 → [看图 P1 ∥ 听对话 P_voice] → 融合夸夸 P2 → 质量闸门 → 防重复闸门 → (演示模式先配音存池) → 播出`

## 常见问题

**Q：浏览器没自动弹出来？**
手动打开 `http://127.0.0.1:5680`（用 127.0.0.1 比 localhost 更快）。

**Q：点「打开镜子」没反应？**
检查是否允许了摄像头权限；确认摄像头没被别的程序占用。

**Q：想让它重新从零开始记（清空"已说过"）？**
删掉 `praise_history.json` 再重启即可。

**Q：改了提示词，这边要重启吗？**
不用。它每次都读最新文件，保存后下一句就生效。

**Q：端口 5680 被占了怎么办？**
说明已经有夸夸镜在跑，直接开浏览器用即可；或先关掉旧窗口再双击启动。
