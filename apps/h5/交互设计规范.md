# 夸夸镜 · 交互设计规范 v1.0

> 归纳自现有实现：`src/components/*`、`src/index.css`、`src/App.tsx`、`server.ts`、`src/data/*`。
> 适用范围：所有新增场景、页面、弹窗、组件。交付前必须按第 9 节自检清单逐项核对。

---

## 1. 产品基调与不可违背的铁律

产品一句话定位：**同一个"想成为的我"，在镜子前夸你一句，在 APP 里陪你说话。**

任何新场景都不得违背以下铁律：

1. **不制造内疚**：不考核打卡天数、无断签惩罚、随时想来就来。
2. **不做主观打分**：AI 绝不给用户的自我接纳度/品质打分；页面上的 1–5 难度分是用户对自己"这件事有多难"的主观感受，且必须可跳过。
3. **先看见你，再建议你**：任何建议/归纳必须先引用用户说过的原话（如"关于这件事，你说过""你 8/12 说…"）。
4. **具体回应 > 空洞夸奖**：禁止"你真棒""你好坚强"式套话；必须回应用户刚说的具体细节。
5. **沉浸感**：对话中禁止出现"AI""镜子""大模型""系统"等词；陪伴者的身份是"想成为的你"。
6. **失败路径永远存在**：每个任务/弹窗都要有温和的退出或搁置出口（"先放一放""跳过不留""暂时不""别再提"），且搁置不产生任何负面反馈。
7. **隐私与安全**：APP 不使用摄像头、不做人脸识别；检测到危机关键词立即中断流程，弹出危机干预弹窗（热线电话 + "回到安全界面"）。

## 2. 整体布局

### 2.1 画布

- 移动端优先：内容统一 `max-w-md mx-auto`（448px），桌面端也保持手机宽度居中。
- 页面留白：横向 `px-4`，纵向 `pt-2`、底部 `pb-24`（为底部导航留空间）或 `pb-28`（同时有悬浮按钮时）。
- 垂直节奏：页面内卡片之间统一 `space-y-4`。

### 2.2 页面骨架（三段式，App.tsx）

```
┌ sticky 顶部 Header（glass-header，z-30）
│  左：你好，{昵称} + 理想自我小字；右：圆形头像（点击→"我"Tab）
├ 可滚动 main（flex-1，按 activeTab 切换四个 Tab 视图）
│  present 此刻 / growth 成长 / review 回顾 / profile 我
└ fixed 底部 Navbar（glass-nav，z-30，4 Tab：此刻·成长·回顾·我）
```

- 顶部 Header 与底部 Navbar 永远 sticky/fixed，内容区独立滚动。
- 悬浮按钮放在 `fixed bottom-20 right-4`（Navbar 上方），z-30。

### 2.3 全屏场景

- 对话（ChatModal）、新手引导（Onboarding）使用 `fixed inset-0 z-40/50` 全屏覆盖层，`bg-[#F8F9FC]`，内部自带顶栏（对话页：返回箭头+同伴头像+重置按钮）。
- 普通弹窗（非全屏）见第 5 节弹窗规范。

| 点赞/危机                           | rose 系（rose-500 实心爱心、rose-600 热线按钮）                                            |
| 解锁提示横幅                        | amber 系（amber-50 底 + amber-200 边框）                                                   |
| 文本层级                            | stone 系：900/800 标题主文、600/700 正文、400/500 辅助说明、300 禁用                       |
| 页面背景                            | `bg-hero-glow`：径向渐变 `#D4ECF8 → #DFDAF3 → #FBF6F4 → #FFF4F0`（顶部冷蓝紫、向下暖米白） |
| 全屏底                              | `#F8F9FC`                                                                                  |

### 3.2 玻璃拟态六级（index.css 定义，直接复用类名）

| 类名                | 场景                                        |
| ------------------- | ------------------------------------------- |
| `glass-card`        | 普通卡片、列表项、可 hover 的卡片           |
| `glass-card-subtle` | 内嵌次级容器：chips、标签、输入框、次级按钮 |
| `glass-card-strong` | 高亮主卡片、对话 AI 气泡、核心信息容器      |
| `glass-modal`       | 弹窗面板、悬浮按钮                          |
| `glass-header`      | 顶部栏、弹窗底部操作栏                      |
| `glass-nav`         | 底部导航                                    |

- hover 反馈：可交互卡片加 `glass-card-hover`（上浮 2px + 阴影加深）。

### 3.3 圆角与描边

- 卡片/面板：`rounded-3xl`（24px）；内嵌容器：`rounded-2xl`（16px）；按钮/选项：`rounded-xl`（12px）；胶囊：`rounded-full`。
- 描边默认 `border-white/90` 玻璃边，或 `border-stone-200/50~70` 细分隔线（卡片内 `border-t` 分隔）。

### 3.4 字体

- 默认：Plus Jakarta Sans（西文）+ PingFang SC / Microsoft YaHei（中文）。
- 诗意文案、用户原话引用、夸夸正文、部分标题：`.font-serif-sc`（Noto Serif SC，衬线）。
- 字号阶梯：`text-[10px]/[11px]` 辅助徽章 · `text-xs`（12px）正文 · `text-sm/base` 标题 · `text-lg/xl` 强调标题（onboarding、危机弹窗）。

### 3.5 氛围光晕与动效

- 高亮卡片角落放两团 `blur-3xl pointer-events-none` 光斑：`bg-[#FF7A50]/15` 与 `bg-[#C8B8D9]/20`。
- 页面进入：`animate-fade-in`；持续引导注意力：`animate-soft-pulse`（3s 呼吸）或 `animate-bounce [animation-duration:3s]`（悬浮按钮）。
- 加载态：三色圆点（橙/紫/薄荷绿）依次 bounce + 文案"正在为你整理温柔的回应…"；按钮 loading 时 spinner + 文案变化 + disabled。
- 过渡：0.2–0.3s，缓动 `cubic-bezier(0.16,1,0.3,1)`。
- 里程碑完成：canvas-confetti 庆祝（配色 #FF7A50/#C8B8D9/#9CD9C9/#FFD166）。
- 滚动条：5px 细滚动条，紫色半透明圆角滑块。


## 5. 信息架构与交互顺序（关键路径）

1. **Onboarding（4 步）**：① 选人格（2 列卡片）+ 理想自我输入 + MBTI 语气基调 → ② 选 2–3 个内耗标签 → ③ 写一句真实的困扰原话 → ④ 承诺页（"我记住了…"）+ 首条专属夸夸预览 → 完成后立即生成一条引用其原话的今日夸夸。
   - 顶部进度条（渐变橙，step/4 宽度），底部"上一步 / 继续下一步"，最后一步"去看看今天的夸夸与此刻 →"。

2. **此刻（默认 Tab，自上而下）**：本月夸夸天数统计卡 → "夸夸镜在线"卡（第一人称"今日夸夸"+ 换一句）→ "今日夸夸记录"列表（夸夸内容优先展示；有原话的可展开"我原本的记录"；每条可点赞）→ 悬浮"想聊聊"按钮（带光晕角标，引导进入对话）。

3. **对话流（ChatModal）**：个性化开场白（必须引用最近 Moment 原话或内耗标签）→ 前 3 轮显示"你可以试试这样倾诉"快捷示例 → 输入/语音 → 发送（发送键空输入禁用）→ loading → AI 回应（2–4 句，结构：共情 → 找亮点 → 鼓励）→ 第 4–5 轮追加柔和收尾句 → 每条 AI 回应附"留下这一段"→ KeepMoment 弹窗（原话可编辑 + 难度分可跳过 + 关联主题）→ 沉淀为 Moment（立即出现在"此刻"列表顶部）。

4. **成长（自上而下）**：主题列表 ──"现在面对的"（进行中主题卡）→ "新的可能"（引用两句原话归纳出的洞察 + 三选一："说得对/暂时不/别再提"）→ "还没打开的"（锁定主题 + "想先开它"投票）。点击主题进详情：返回按钮 + "查看成长故事卡" → "关于这件事，你说过"（原话墙）→ 蜿蜒山路里程碑路径（已完成=emerald 勾 / 进行中=橙色呼吸星 / 未解锁=灰数字，竖线渐变连接）→ 点击进行中里程碑 → MilestoneModal：引导思考 → 微小行动任务 → 写体会 → 选纪念照（选填）→ 难度滑杆 → "我做到了" → confetti → 成功页（星星 + AI 专属回应 + "收下肯定，继续向前"）；或"先放一放"搁置。

5. **回顾（自上而下）**：标题 + 搜索切换按钮 → 镜面记忆星图卡（5 个 ✦ 瞬间进度解锁，镜中照片随进度从模糊变清晰）→ "查看月度总结"（解锁前可预览、带 amber 提示横幅）→ 📅 我的记忆日历（标记：· 留痕 / ✦ 突破 / 🌱 启程，点击有标记的日期筛选，可"显示全部"）→ "最近留下的瞬间"时间线（原话 + AI 回应 + 点赞）→ 月度总结弹窗（见证语 + 数据格 + 高光瞬间 + 分享按钮）。

6. **我（自上而下）**：头像信息卡 → "── 我想成为的自己 ──"（可修改）→ "── 我的人格设定 ──"（人格 2 列切换 / MBTI 4 列选择 / 说话风格胶囊）→ "── 我在意的内耗主题 ──"（标签编辑）→ "── 硬件与隐私 ──"（连接镜子开关 / 隐私说明弹窗 / 使用理念弹窗 / 重新体验引导）。

7. **危机干预（最高优先级，可打断任何流程）**：输入含危险关键词 → 立即弹 CrisisModal（rose 图标 + 热线号码 + "立即拨打"tel: 链接 + "我已知晓，回到安全界面"）。

## 6. 文案与语气规范

- **口吻**：陪伴者 = 用户"想成为的自己"；今日夸夸 = 第一人称"我"对自己说的话。
- **结构**：共情（接住情绪）→ 找亮点（从经历中找行动证据，常使用"手在抖和还是举了手，这两件事是同时发生的"这类并置）→ 鼓励（给托底力量）。
- **引用原话必须准确**，不得编造历史。
- **长度**：单轮回应 2–4 句；今日夸夸 35–75 字；里程碑回应 2–3 句且要点出提交文字里的具体细节。
- **禁止**：空洞套话、说教、MBTI 事实断言（MBTI 仅决定语调软硬）、出现"AI/镜子/大模型/系统"等词。
- **时间格式**：`刚刚`（即时产生）、`今天`（当日）、`8月26日`（历史日期）。
- **语气词与标点**：多用"…"、温和设问（"今天怎么样？有什么事在心里绕着吗？"）；关键数字用加粗高亮。

## 7. 工程与命名约定（新增代码遵循）

- 技术栈：React 19 + TypeScript + Vite + Tailwind CSS v4 + lucide-react；后端 Express。所有 AI 回应为内置虚拟文案（无外部依赖，离线可用）。
- 类型集中在 `src/types.ts`；枚举值用英文蛇形：`pending / in_progress / completed / paused / stalled`、`accepted / paused_30d / muted`。
- id 前缀：`m_` Moment、`p_` Praise、`ms_` Milestone、`theme_` Theme、`np_` NewPossibility、`dr_` 日回顾、`wr_` 周回顾、`msg_` 消息。
- 组件命名：页面级 `XxxTab.tsx`、弹窗 `XxxModal.tsx`；props 回调统一 `onXxx`；受控弹窗统一 `isOpen / onClose`。
- 状态管理：App.tsx 集中持有领域状态，Tab/Modal 组件通过 props 回调上报；UI 局部状态（展开、选中、编辑态）留在组件内。
- API 约定：`/api/chat`、`/api/generate-praise`、`/api/milestone-response`、`/api/safety-check`；AI 失败必须走本地兜底文案，前端 catch 后同样兜底，绝不让用户看到错误。
- 关键交互控件加稳定 `id`（如 `chat-send-btn`），便于自动化验证。

## 8. 新增场景设计流程

1. 先声明场景目标与入口位置（从哪个 Tab/按钮进入、如何返回）。
2. 套用骨架与玻璃六级、色板、圆角、字号阶梯（第 2–3 节）。
3. 按交互顺序铺内容（第 5 节对应流程），保证：先引用原话 → 再给内容 → 行动出口清晰 → 失败/搁置路径存在。
4. 文案按第 6 节语气撰写，AI 生成内容需在服务端 prompt 中继承第 6 节约束。
5. 完成后按第 9 节自检，输出"合规自检结果"（逐项通过/未通过及理由）。

## 9. 新场景合规自检清单

- [ ] 布局：max-w-md 居中、px-4、pb-24/28 留白、上下结构遵循三段式骨架
- [ ] 颜色：只用 3.1 色板；主 CTA 为 #FF7A50 系；无新引入颜色
- [ ] 玻璃层级：卡片用对 glass-card 系列类名（主卡 strong / 列表 card / 内嵌 subtle / 弹窗 modal）
- [ ] 圆角与字号：3xl/2xl/xl/full 阶梯正确；字号在 10px–xl 阶梯内
- [ ] 字体：引用/诗意文案使用 font-serif-sc
- [ ] 动效：进入用 animate-fade-in；引导注意用 soft-pulse / bounce(3s)；有 hover 反馈
- [ ] 按钮层级：主（橙渐变）/次（subtle）/中性（stone-900）/文本链接 四级正确，无歧义
- [ ] 弹窗：z-50 遮罩 + glass-modal + X 关闭 + 底部操作区模板
- [ ] 输入：focus 紫色 ring、口语化 placeholder
- [ ] 难度分（如涉及）：1–5 滑杆 + 可跳过 + "纯属主观感受"说明
- [ ] 流程顺序：先引用原话 → 内容 → 行动出口；有明确返回路径
- [ ] 失败/搁置路径：存在且无任何惩罚性反馈
- [ ] 文案：无空洞夸奖、无"AI/系统"等词、长度符合约束、引用原话准确
- [ ] 状态完整：空态、loading、disabled、成功反馈（如 confetti）齐全
- [ ] 命名：类型入 types.ts、id 前缀、onXxx 回调、Tab/Modal 命名符合第 7 节
