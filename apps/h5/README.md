# 夸夸镜 · AI情绪支持伴侣

同一面"想成为的自己"，在镜子前夸你一句，在APP里陪你说话。

> 本项目为黑客松演示版本：**所有 AI 回应均为内置虚拟数据**，无需 API Key、无需联网即可运行。

## 本地运行

**前置要求：** Node.js

1. 安装依赖：
   `npm install`
2. 启动开发服务器：
   `npm run dev`
3. 打开 http://localhost:3000 即可使用（手机壳布局，可开浏览器手机模拟器体验）

## 生产构建

`npm run build` 后 `npm run start`（服务 http://localhost:3000）。
