# ADR-005: 出厂激活与设备制品存储

**状态**: 已接受  
**日期**: 2026-08-29

设备以出厂预置、一次性使用的激活码完成首次配对；后端仅保存激活码和设备令牌的哈希。图片历史与 OTA 固件使用 Supabase Storage 私有 Bucket，PostgreSQL 保存元数据；没有管理员页面时，激活码导入和固件发布只通过开发者本机命令执行。OTA 制品使用 SHA-256 校验并由 Ed25519 签名发布，仅投放匹配设备型号且版本更高的 stable 固件；设备通过短时下载 URL 获取制品。图片上传不隐式触发模型调用，模型接口按设备合并限流。该决定取代 ADR-004 中“设备激活、固件升级不在 MVP”的范围约束。
