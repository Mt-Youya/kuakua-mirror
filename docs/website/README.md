# 夸夸镜产品与官网设计文档

本目录记录品牌、产品和体验方向，不是当前后端接口或部署事实。运行时契约以 `packages/api-docs/openapi.json`、`apps/backend` 控制器和 K10 固件为准。

- `product-requirements.md`：定位、用户、MVP 与隐私原则。
- `website-design.md`：官网信息架构、视觉与动效。
- `ai-prompt-design.md`：陪伴人格、夸夸原则、情绪边界与安全规则。
- `technical-architecture.md`：早期技术架构设想。

已落地演示包括 [H5 应用](../../apps/h5/README.md) 与 [K10 固件链路](../../hardwares/firmware/README.md)。Waitlist、WebRTC、MQTT、长期记忆和官网 3D 等内容不应视为已实现功能。
