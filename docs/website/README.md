## 1. 项目一句话介绍

夸夸镜是一面能够看见用户、听见用户、理解用户，并在合适的时候给予自然、具体、克制的积极反馈的 AI 智能镜子。

核心品牌表达：

> **这一次，镜子站在你这边。**

我们不是希望女性变得“更完美”，而是希望她能够发现：

> **现在的自己，也已经很好。**

## 5. 核心原则

### 女性不等于粉色

视觉风格应温柔、高级、克制，而不是依赖刻板女性视觉。

### 情绪价值优先于 AI 技术参数

用户不需要先知道模型名称、Token、参数量。

用户首先应该感受到：

> 它真的注意到了我。

### 具体优于空洞

不要：

> 你很棒。

优先：

> 你刚才讲那件事情的时候其实很有条理。

### 被理解优于被教育

夸夸镜不是老师、心理医生或人生导师。

它更像一个：

> **很会发现你优点、也知道什么时候不要说教的朋友。**
