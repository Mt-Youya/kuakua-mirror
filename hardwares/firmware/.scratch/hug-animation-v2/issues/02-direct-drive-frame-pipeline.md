# 02: 直推管线 + 时间线骨架

**What to build:** 动画期接管屏幕:停用 Canvas 渲染,在高带宽内存分配 240×320 RGB565 帧缓冲,以独立显示驱动实例按"帧间变化的行带"直推上屏;先用红/蓝纯色帧核对字节序;再搭三阶段(合拢 / 抱住 / 退场)连续时间轴与缓动求值,用可动的简色块在时间线上作可视化验证;动画结束归还 Canvas,画回待机页。串口打印动画起止各一次。

**Blocked by:** None (can start immediately)。

**Status:** ready-for-agent

- [ ] 短按 B:屏幕交出、纯色/色块演示帧丝滑(帧率打点 ≥30 FPS,目标 ≥40 FPS)
- [ ] 红蓝纯色帧色彩正确(字节序方向已核对并固化)
- [ ] 动画结束干净切回待机页,无花屏、无残留
- [ ] 动画期间不存在任何 Canvas 绘制/刷新调用
- [ ] 串口 `hug action=start` / `hug action=complete` 各一次
