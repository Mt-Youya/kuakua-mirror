# 01: Hug 文案位图生成工具链

**What to build:** 一个可重复运行的构建期脚本:把句库里的每句暖心短句(≤8 字)用本机中文字库渲染成单行掩码位图(240×40,1bpp),生成可直接被固件引用的常量头文件;字节序、行序、句序与句库一致,产出逐字可查。

**Blocked by:** None (can start immediately)。

**Status:** ready-for-agent

- [ ] 脚本可在干净环境重复运行,产物字节级确定
- [ ] 8 句文案全部生成,掩码像素与句子字形一一对应(自检解码通过)
- [ ] 同一句的掩码位宽 ≤240、高 ≤40,长句自动居中
- [ ] 生成的头文件含:每句掩码字节流、宽高宏、句索引(与句库顺序一致)
