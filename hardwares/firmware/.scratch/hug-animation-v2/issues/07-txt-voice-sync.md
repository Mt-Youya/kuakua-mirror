# 07: 文案语音同步播报

**What to build:** 拥抱完成、文字淡入的瞬间,板载离线中文语音合成(esp_tts,小乐音色)同步读出屏幕上的同一句暖心文案;整句预先解析,淡入瞬间开始流式播放,不阻塞动画;TTS 初始化失败时静默降级,动画与文字照常。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 语音内容与屏幕显示的句子一致(同一随机句)
- [ ] 开嗓时刻与文字淡入同步(误差 <0.2s),整句连贯不卡断
- [ ] 语音全程离线,不触发任何网络请求
- [ ] 动画帧率不受语音影响(语音走音频通道,渲染管线不变)
- [ ] TTS 初始化失败:动画照常,串口有降级日志,不报错页
- [ ] 动画中途被打断或结束,语音同步停止,无残余发声
