# K10 Hug Animation v2 — 分镜规范

短按 B 键触发的抱抱动画重设计。目标：丝滑（无步进感）、贴合瓷白银线画廊调性、让人真正感到「被抱了一下」。

## 视觉叙事

**隐喻**：两根银弧像手臂，从屏幕两侧缓缓合拢，把中间的月亮环拥入怀；拥抱让月亮圆满、让柔光亮起；随后弧线松开，对称退场。

**画面元素（纯净构图）**：

- 月亮：位于上部中心（中心 ≈ (122, 74)，半径 ≈ 46）
- 弧线：一对细银弧（2~3px，COL_SILVER 系），从两侧伸入，最终与月亮同心贴合
- 柔光晕：抱住瞬间泛起雾蓝同心柔光（COL_HALO_INNER / COL_HALO_OUTER 系），逐层扩散收敛
- 文案：屏幕下部居中（y ≈ 210），抱住瞬间整句柔光淡入 + 轻呼吸
- 底部细线：y = 272，60px 宽（COL_HAIRLINE）
- 不出现待机提示文字，无 WiFi 状态

## 时间轴（总长 ≈ 3.5s）

| 阶段 | 时长 | 画面 |
| --- | --- | --- |
| 0 合拢 | ≈ 1.8s | 双弧从两侧收拢；月牙同步丰盈成满月（easeInOut，无步进感）；月光 SILVER → SILVER_LIT |
| 1 抱住 | ≈ 1.2s | 弧线贴住满月、轻微收紧过冲后回弹；雾蓝光环扩散；文案整句柔光淡入 + 呼吸 |
| 2 退场 | ≈ 0.8s | 弧线同步松开退向两侧；满月还原月牙；柔光与文案渐熄 → 切回待机页 |

## LED 编排（板载 RGB，暖杏 0xFFA26B）

- 合拢：亮度随 progress 渐亮（rank 低 → 中）
- 抱住：最亮呼吸（与满月呼吸同频）
- 退场：渐暗 → 待机微呼吸

## 语音播报（板载离线 TTS）

- 引擎：esp_tts 中文离线合成，小乐音色（库内置，无需烧录模型），全程离线
- 内容：与屏幕显示的同一句暖心文案
- 时机：文字淡入的同一瞬间开嗓，整句在 hugStart 时预先解析，淡入时流式播放
- 降级：TTS 初始化失败 → 静默照常播动画，串口记降级日志

## 文案

沿用 `HUG_COMFORT_LINES` 8 句随机句库（相邻不重复）。整句浮现，非逐字。

## 验收观测

1. 短按 B → 动画完整播放后回待机，串口 `hug action=start/complete` 各一次
2. 肉眼：无跳变/步进感；弧线-月亮-光环-文案动效层次清晰；整体约 3.5s
3. LED：合拢渐亮 → 抱住呼吸 → 退场渐暗
4. 相邻两次按压文案不同

## 实现约束

- 非阻塞：由 loop 中 `hugTick()` 推进，不占用长 `delay()`
- 所有运动用连续时间插值 + easing，杜绝「每 N ms 跳一步」的观感
- 帧率与上屏方案见 ADR 0002：动画期间停用 LVGL Canvas 路线，自建 PSRAM 帧缓冲 + 独立 TFT_eSPI 直推（按脏行带推送，目标 ≥40 FPS），动画结束后归还 Canvas
- 动画期间忽略所有按键；B 键长按 800ms 重连逻辑不变
- 文案位图在构建期由脚本从字库预渲染生成，运行时只做掩码淡入
